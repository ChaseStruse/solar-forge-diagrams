# Offline infrastructure import, layout, and resource reachability

The user authorized these additions after the original alpha scope was written. They supersede the earlier deferral of Terraform imports and automatic layout; live AWS discovery remains deferred.

Imports normalize Terraform resource blocks, evaluated state/plan resources, CloudFormation resources, and Compose services/networks into the portable document. The pipeline retains an allowlist of diagram/network properties. It does not execute infrastructure code or persist whole state values, user-data scripts, or Compose environment maps. Preview warnings and the document validator run before replacing the current board. Unknown expressions and unsupported network constructs remain explicitly incomplete so they cannot silently supply permission.

The layout engine is local TypeScript with no added graph-layout dependency. It projects edges onto sibling boundaries, ranks acyclic nodes, places remaining cycles in a final layer, packs disconnected sets, and resizes boundaries from the inside out. This guarantees sibling separation and containment for valid input, not optimal connector crossing reduction. Imports use the same engine as the undoable Automatic layout command.

Security groups, ACLs and route tables are policies on resource nodes. Attachments are ID references, validated on document load and remapped/pruned during clipboard operations and deletion. The evaluator checks SG allow unions in both endpoint directions, priority-ordered request/return ACLs, longest-prefix routing, local VPC routes, public IGW ingress/egress and public NAT egress. It supports IPv4 and returns Unknown when information or modeled routing behavior is insufficient. No assigned ACL assumes the default allow ACL, and external routing after an IGW is assumed available; the UI states these assumptions. It does not certify deployed infrastructure, application listeners, DNS, load balancer behavior, peering, transit gateways, private NAT routing or IPv6.

AWS semantics were checked against the primary references for [security-group rules](https://docs.aws.amazon.com/vpc/latest/userguide/security-group-rules.html), [network ACL behavior](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-network-acls.html), and [route priority](https://docs.aws.amazon.com/vpc/latest/userguide/route-tables-priority.html). Terraform evaluated input follows the [documented JSON representation](https://developer.hashicorp.com/terraform/internals/json-format). HCL source import intentionally handles a static subset; evaluated JSON is the path for expanded modules and instances.

## Runtime dependency review

`yaml` **2.9.1** is pinned in package.json and bun.lock. It provides offline YAML parsing, anchors/merge handling, alias expansion limits, and preservation of CloudFormation tags. Its **ISC** license permits redistribution with the copyright/license notice; the notice is included by scripts/collect-licenses.py and listed in THIRD_PARTY_NOTICES.md. The [maintained upstream TypeScript project](https://github.com/eemeli/yaml) documents browser support and custom tags. Handwriting a YAML reader was rejected because correctly handling quoted values, multiline scalars, aliases and CloudFormation tags is materially broader than the supported static HCL reader. Calling a system Terraform/Compose binary was rejected because imports should not require those tools or execute source code.

The production infrastructure-import chunk (parser plus format adapters) is about **38 KB gzip**, loaded only when an import is requested. The initial JavaScript remains about **220 KB gzip**, within the 350 KiB project budget. The layout and policy evaluator add no further dependencies.

Validation includes portable roundtrips, import fixtures, layout containment/separation and undo, security-group union and peers, route priorities and return paths, ACL priority and reply ports, NAT/IGW behavior, incomplete/conditional policy handling, and reference-safe editing. Browser checks cover import previews, file selection, rule editing and undo, matrix results, journey tracing, and checked-path GIF export. Native dialogs and the Rust command need validation on a machine with the Rust/Tauri toolchain.
